**Reading order for someone new:** product plan, then the rules README, then the MVP plan and status.

**Keeping docs true:** a change that makes a doc wrong updates the doc in the same pull request. A major decision adds a line to DECISIONS.md. A milestone that moves updates STATUS.md.
